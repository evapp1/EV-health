# UI/UX MVP Baseline Approval

**Status:** Approved  
**Effective date:** 30 July 2026  
**Approved document:** `EV_Health_UI_UX_Design_Specification_v1.0.md`  
**Approved version:** 1.0

## Decision

The EV Health UI/UX Design Specification version 1.0 is approved as the MVP implementation baseline.

This approval supersedes the earlier `Draft for MVP implementation` status text in the document header. Until the source document header is revised in place, this approval record is authoritative for document status.

## Scope of approval

The approval covers the Android-first BYD Dolphin Premium MVP experience defined in the specification, including:

- onboarding and permission education
- adapter discovery and connection flows
- vehicle confirmation
- scan preparation and scan-progress behaviour
- result summary and full report
- metric explanations and provenance
- history and saved reports
- PDF and image export
- settings, privacy, demo mode, and Developer Mode
- accessibility, responsive behaviour, error handling, and testing requirements

## Governing relationship

This document does not change the project authority order. The combined SDS / Constitution and product-requirements baseline remains the highest-authority project document. The Architecture Specification governs technical structure. The approved UI/UX Specification governs presentation and user-flow behaviour within those constraints.

## Change control

Future material UI/UX changes must be recorded through an approved document revision or architecture/product decision. Coding agents must not reinterpret unresolved design decisions silently.
